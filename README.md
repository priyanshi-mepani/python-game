# AstroBlast: Space Explorer 🚀

A 2D space exploration game developed in Python using Pygame as part of my BTEC IT coursework.

## About the Game

AstroBlast: Space Explorer is a space-themed arcade game where the player controls a rocket, collects stars and gems, avoids UFOs, and uses a shield power-up to survive.

The game includes three difficulty levels and four selectable rocket skins.

## Features

- 🚀 Rocket movement using Arrow Keys or WASD
- ⭐ Collectible stars worth 10 or 20 points
- 💎 Gems worth 30 points
- 👽 UFO enemies
- 🛡️ Shield power-up providing temporary invincibility
- ❤️ Lives system
- ⏱️ Timed gameplay
- 🎮 Three difficulty levels
- 🎨 Four selectable rocket skins
- ✨ Particle effects and explosion animations
- 🎵 Procedurally generated background music
- 🏆 Best-score tracking
- 📋 Menu and game-over screens

## Difficulty Levels

| Level | UFOs | Lives | Time |
|---|---:|---:|---:|
| Cadet | 2 | 3 | 60 seconds |
| Pilot | 4 | 2 | 45 seconds |
| Ace | 6 | 1 | 30 seconds |

## Controls

| Control | Action |
|---|---|
| Arrow Keys / WASD | Move the rocket |
| Z / X | Change rocket skin |
| Left / Right | Change difficulty |
| Enter / Space | Start or restart |
| M | Return to menu |
| ESC | Return to menu |

## Technologies Used

- Python
- Pygame
- Object-oriented programming

- Game loops and event handling
- Collision detection
- Particle effects
